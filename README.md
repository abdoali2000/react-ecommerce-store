# 🎭 Maison Velvet
### High-End Luxury E-commerce Experience

**Maison Velvet (Velvet Cartel)** is a premium, high-performance e-commerce storefront designed with a focus on dark luxury aesthetics, seamless user experience, and robust state management. 

---

## ✨ Key Features

* **🌑 Dynamic Luxury UI:** A sophisticated "Dark Mode" first interface using a **Burgundy, Gold, and Black** palette.
* **🌓 Theme Switching:** Fully integrated Dark/Light mode toggling powered by **Redux**.
* **⚡ Modern Stack:** Built with **React 18** and **Vite** for lightning-fast performance.
* **🎨 Smooth Animations:** Subtle entrance and interaction animations using **Framer Motion**.
* **📱 Responsive & Interactive:** Fully responsive design with interactive elements like the **Hero Slider** and **Product Carousels**.
* **🛠️ State Management:** Global state handling for Cart, Theme, and Language using **Redux Toolkit**.
* **🌐 Multi-Language Support:** Full support for **Arabic (RTL)** and **English (LTR)**.

---

## 🚀 Tech Stack

| Technology | Usage |
| :--- | :--- |
| **React.js** | Library for building the UI |
| **Vite** | Fast Next-generation frontend tooling |
| **Redux Toolkit** | State management (Cart, Theme, Auth) |
| **Tailwind CSS** | Utility-first styling & Dark Mode |
| **Framer Motion** | Advanced animations and transitions |
| **Lucide React** | Premium icon set |
| **React Router** | Client-side routing |
